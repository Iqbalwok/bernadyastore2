Deskripsi Aplikasi

GitHub Copilot adalah partner pemrograman kecerdasan buatan paling dicintai oleh jutaan developer software di seluruh dunia. Dilatih pada miliaran baris kode open source, Copilot memahami logika program Anda dan menyarankan baris atau seluruh fungsi kode secara instan.

Bekerja mulus di dalam VS Code, IntelliJ, PyCharm, dan Visual Studio. Cukup ketik komentar bahasa manusia, dan saksikan Copilot menuliskan implementasi kodenya untuk Anda.

Fitur Utama & Keunggulan

Berikut adalah fasilitas utama yang dapat Anda nikmati melalui layanan aplikasi ini:

Pelengkapan kode otomatis (Code Autocomplete) dalam puluhan bahasa pemrograman.
Copilot Chat terintegrasi di editor untuk tanya jawab bug, refactoring, dan arsitektur.
Pembuatan unit test otomatis untuk memvalidasi fungsionalitas software Anda.
Penjelasan kode legacy yang rumit ke dalam bahasa manusia yang mudah dipahami.
Dukungan penuh untuk Python, JavaScript, TypeScript, PHP, Go, C++, dan Java.

Informasi & Panduan Penggunaan

Alur standar untuk mulai menggunakan dan mengoptimalkan akun aplikasi Anda:

1
Tautkan akun GitHub Anda ke lisensi Copilot yang diaktivasi tim Bernadya.
2
Pasang ekstensi "GitHub Copilot" resmi di editor VS Code atau JetBrains.
3
Login ke akun GitHub Anda melalui jendela editor.
4
Mulai koding dan tekan tombol `Tab` untuk menerima saran kode cerdas.

Pertanyaan Seputar GitHub Copilot

Ya, VS Code adalah platform utama GitHub Copilot dengan integrasi Copilot Chat di sidebar.
Mendukung hampir seluruh bahasa pemrograman populer: JavaScript, TypeScript, Python, PHP, Java, C#, Go, HTML, CSS, SQL, dan lain-lain.
